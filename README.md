# tracestream

Trace timestamps and stream durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/tracestream/

## Install / run

```bash
git clone https://github.com/theworker02/tracestream.git
cd tracestream
node src/cli.js
node --test
```
